# SQL Book Database

My project is a database about books. It stores information about authors, genres, publication years, and book titles. The database also allows users to run queries to view books, filter by genre, and see relationships between books, authors, and genres.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install MySQL Server and MySQL Workbench (or another SQL client).
2. Open the SQL script file in MySQL Workbench.
3. Run the script to create the mylibrary database, tables, sample data, and queries.

Instructions for using the software:

1. Open MySQL Workbench and connect to your local MySQL server.
2. Run the provided SQL script to create and populate the database.
3. Execute the example SELECT queries to explore books, authors, genres, and filtered results.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* MySQL Server 8.0+
* MySQL Workbench 8.0+
* SQL language
